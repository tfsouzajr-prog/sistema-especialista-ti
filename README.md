# Sistema Especialista: Consultor de Carreiras em TI

Este projeto utiliza Python, Experta e Streamlit para atuar como um Consultor Inteligente, recomendando uma das 10 trilhas de carreira em TI com base no perfil do utilizador.

## Tecnologias Utilizadas
- Python 3.10+
- Experta (Motor de Inferência Baseado em Regras)
- Streamlit (Interface Gráfica Web)
